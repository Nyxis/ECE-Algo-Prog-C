# ECE — Algo & Programmation C (B1)

## Mise en place (une seule fois)

1. Ouvrir CLion
2. File > New > Project from Version Control
3. Coller l'URL : `https://github.com/Nyxis/ECE-Algo-Prog-C.git`
4. Cliquer Clone
5. En bas à droite de CLion, cliquer sur `main`
6. Cliquer `New Branch`
7. Nommer la branche : `prenom-nom` (en minuscules, sans accent)
8. Cocher `Checkout branch`, valider

## Rendu de TP (à chaque fin de séance)

1. En haut de CLion : Git > Commit (ou Ctrl+K)
2. Cocher les fichiers à envoyer
3. Écrire un message : `TP du JJ/MM`
4. Cliquer `Commit and Push`
5. Vérifier que la branche affichée est bien `prenom-nom`, puis Push

## Règles

- Ne jamais push sur `main`
- Ne jamais push sur la branche d'un autre étudiant
- Tout push sur une branche qui n'est pas la vôtre sera traité comme du plagiat (RI §4.6c)
